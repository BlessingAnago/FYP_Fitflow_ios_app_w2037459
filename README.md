 FitFlow :Running Guide (iOS, SwiftUI, 
MVVM) 
 
This guide explains how to access the project, open it in Xcode, build it, and run the app for assessment. 
1.	Access the Project Repository 
The full source code is available on GitHub: 
🔗 Repository Link:  https://github.com/BlessingAnago/FYP_Fitflow_ios_app_w2037459.git
To view the project online: 
•	Open the link in any browser 
•	Browse through the folders, Swift files, and architecture 
•	Review documentation and screenshots 
 
2.	Download or Clone the Project 
Option A — Download ZIP (Simplest) 
1.	Visit the GitHub repository 
2.	Click the green Code button 
3.	Select Download ZIP 
4.	Extract the ZIP file to your Mac Option B — Clone using Git 
If Git is installed: 
git clone https://github.com/BlessingAnago/FYP_Fitflow_ios_app_w2037459.git
 
3.	Open the Project in Xcode 
Requirements 
•	macOS 
•	Xcode 14 or later (recommended) 
•	iOS Simulator or a physical iPhone (optional) 
Steps 
1.	Open Xcode 
2.	Select File → Open 
3.	Navigate to the extracted/cloned project folder 
4.	Open the file: 
FitFlow.xcodeproj or FitFlow.xcworkspace  
(depending on your project structure) 
Xcode will load the project and index the files. 
 
4.	Build the App 
Once the project is open: 
1.	Select a simulator (e.g., iPhone 15, iPhone 14 Pro) from the device dropdown at the top 
2.	Press ⌘ + B to build the project 
3.	Ensure the build completes without errors 
 
5.	Run the App 
To launch FitFlow: 
1.	Press ⌘ + R 
2.	The iOS Simulator will open automatically 
3.	The FitFlow app will install and run on the selected device 
You can now interact with the app exactly as a user would. 
 
6.	App Features to Explore 
While testing, the lecturer can explore: 
•	Home Dashboard 
•	Workout Categories 
•	Exercise Details 
•	User Progress Tracking 
•	Navigation built with SwiftUI 
•	MVVM structure (Models, Views, ViewModels) 
•	Smooth animations and UI responsiveness 
7.	Project Architecture (MVVM Overview) 
FitFlow follows the MVVM architecture, structured as: 
•	Models – Data structures representing workouts, exercises, and user progress 
•	Views – SwiftUI screens and UI components 
•	ViewModels – Logic, state management, and data binding between Views and Models 
This ensures clean separation of concerns and easy maintainability.
